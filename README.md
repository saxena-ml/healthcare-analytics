# 🏥 Healthcare Analytics — SQL Case Study

## 📌 Overview

A SQL-based healthcare analytics project focused on analyzing **patients, hospitals, admissions, treatments, costs, and length of stay**.

## 📊 Analysis Includes

* Patient demographics and average age
* Hospital admissions and utilization
* Treatment costs and hospital revenue
* Average length of stay
* Patients staying more than 7 days
* Treatment frequency
* Complete patient histories

## 🛠️ SQL Concepts

* SELECT & WHERE
* INNER JOIN & LEFT JOIN
* GROUP BY & Aggregate Functions
* Date Calculations
* Subqueries
* Views
* RANK() & DENSE_RANK()

## 🎯 Objective

To use SQL to generate meaningful **operational and financial insights** from healthcare data.

**Skills:** SQL | Data Analysis | Healthcare Analytics | MySQL
